# מניפה סטודיו — סרטון ארוך נכנס, רילס יוצאים

אפליקציית ווב פרטית: מעלים סרטון (עד שעה ומעלה), בוחרים כמה רילס ובאיזה אורך, ומקבלים גלריה של קליפים
9:16 עם כתוביות עברית מילה-מילה, הוק בראש המסך, SRT וטקסט לפוסט. העיבוד רץ ברקע, אפשר לסגור את הדף.

```
העלאה ──► אודיו (ffmpeg) ──► תמלול (Groq / ElevenLabs / מקומי) ──► Claude בוחר 8+ רגעים לפי ההקשר של מניפה
        ──► לכל קליפ: חיתוך → 9:16 → כתוביות + הוק (reel.py) ──► גלריה: צפייה, הורדה, SRT, טקסט
```

## הרצה מקומית (ללפטופ, לבדיקה)
```bash
pip install -r services/menifa-studio/requirements.txt
cd services/menifa-studio && STUDIO_PASSWORD=1234 ANTHROPIC_API_KEY=sk-ant-... GROQ_API_KEY=gsk_... uvicorn app:app --port 8765
# → http://localhost:8765
```
בלי מפתחות: תמלול מקומי (דורש `pip install faster-whisper`, איטי על CPU) ותכנון היוריסטי.

## הרצה על שרת (המסלול האמיתי)
```bash
cp .env.example .env   # למלא סיסמה + מפתחות
docker compose up -d --build
```
Hetzner CX32 (4 vCPU, 8GB) מספיק: התמלול ב-API, הרינדור של 8 קליפים × 45 שנ' לוקח כמה דקות על CPU.
חשיפה החוצה: Cloudflare Tunnel לדומיין `studio.menifa.org`. הסיסמה נשמרת בדפדפן.
